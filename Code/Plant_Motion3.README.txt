README for Plant_Motion3.py

About Plant_Motion3
--------------------------
Plant_Motion3, developed from Plant_Motion2 during Summer 2023, is a Microsoft Excel workbook generating
program, for working with large numbers of plant images. The accepted image formats are .jpg and .png files.

The program works by looking in a folder, then compiling data for each folder within that folder, and presenting
that data within a neat Excel file.

Example of folder structure)
- Experiment 1 <-- (this is the folder that Plant_Motion3 works out of)
- - plant 1 <-- (this is the folder with all images for plant 1)
- - - pic 1.jpg <-- (this is a picture)
- - - pic 2.jpg
- - - pic 3.jpg

- - plant 2
- - - pic 1.jpg
- - - pic 2.jpg
- - - pic 3.jpg

- - plant 3
- - - pic 1.jpg
- - - pic 2.jpg
- - - pic 3.jpg


How to use Plant_Motion3
--------------------------
1) Organize your images. This program was designed to fit file structures generated by the SMART Table, 
so your directories will need to be organized like the example above.


2) Download the python file and ensure all imports are installed. You will know an import is not installed
if you run the program and get an error similar to "ModuleNotFoundError: No module named 'xlsxwriter'". 

In Pycharm, this can be fixed by going to
File > Settings > Project: (Project name) > Python Interpreter, and clicking on the '+' at 
the top of the table.


3) (The Most Important Step)
At ~line 164 in the main procedure, replace the existing folder location with the location that you would 
like to work out of. Remember, this folder is the outer folder containing folders for each plant.

The line in question should look like this:
os.chdir(r"C:\Users\hpruitt\OneDrive - Institute for Advanced Learning and Research\Desktop\test")

Here, the program changes to the directory specifed by the path. Including the r before the string is
important as it instructs the computer to treat it as a raw string and ignore and special characters 
caused by the '\' character.


4) Ensure that the old Excel sheet is closed. You do not need to delete the generated file between every 
run, but XlsxWriter cannot overwrite the old file while it is still open.


Output
--------------------------
After running, the program will output an excel workbook in the folder from the os.chdir() line, 
containing 3 sheets.

Motion_Worksheet contains data on the movement of green pixels between photos (within a range outlined in 
the IsolateGreen function).

Size_Worksheet contains the count of green pixels for each photo (within range).

Growth_Worksheet contains the difference in values from the Size_Worksheet, indicating growth/shrinkage.
This sheet is useful for understanding error due to the camera, where values indicate shrinkage 
during growth phases. On this sheet, each plant also has a Percent Green Pixel Flux, which takes the 
average difference between pictures (absolute value) as a percentage of the total pixels that makeup the photo.
(Total pixel count is calculated from the first photo and assumes all pics are the same resolution)


For further development
--------------------------
Moving forward, the masking values/method could be improved. In the function IsolateGreen(), there 
are several sections of code that are commented out. These express color ranges related to specific plants,
(with the most recent configuration being setup to work with Mother of Thousands plants). 

Adjusting these values affects the binary image data returned by the function, and they can be changed in the 
future to reduce noise/fluctuations between images and better fit new plants that come under study.
